## 二、评审得分点自检表

对照参赛指南「评审通用规则」，逐项检查材料是否覆盖：

### 2.1 场景适配性（20 分）

- [ ] 明确学段：高等本科院校，结构化学课程（专业基础课）
- [ ] 明确痛点：晶体结构微观构型抽象、三维空间认知困难、专业软件门槛高、教学资源展示形式受限、**看懂结构却仍做不对题**
- [ ] 明确人群特征：化学、材料、化工专业本科生与授课教师，移动端原生用户
- [ ] 明确落地需求：课前预习、课堂教学、课后学习、实验教学四个环节全覆盖
- [ ] 说明产品定位：**不区分教师端与学生端**，同一工具功能兼顾（演示模式 + 练习板块 + 答疑），降低推广门槛
- [ ] 痛点与方案的对应关系清晰（在作品介绍 PDF 中做一张“痛点—功能—成效”对照表）

### 2.2 技术规范性（25 分）

- [ ] 说明技术选型：Vite + Three.js + 原生 ES Module + Serverless 后端
- [ ] 说明系统架构：三层架构 + 智能体层（附架构图）
- [ ] 说明流程设计：**工具调用（Tool Use）而非纯文本生成** —— 这是与“问答型大模型”的技术分水岭
- [ ] 说明人机协同逻辑：AI 生成 → 标注来源 → 人工复核 → 发布
- [ ] 说明数据安全与隐私保护：匿名 ID、本地优先、脱敏传输、双向内容过滤
- [ ] 说明人工复核机制：待审队列 + 审计留痕（见方案 §6.1）
- [ ] 说明额度体系与 BYOK 安全设计：凭据只存本机、不入服务器、不进日志（见方案 §6.5）
- [ ] 如实说明所使用的平台、工具、模型及其来源（赛事明确要求）

### 2.3 创新优化性（20 分）

- [ ] 创新点一：**可解释的晶体学动作**——每个操控动作绑定一个晶体学概念，把工具调用变成教学动作
- [ ] 创新点二：**错误可视化诊断**——答错时不直接给答案，而是把场景切换到能揭示错误根源的状态
- [ ] 创新点三：**练习—结构双向闭环**——做题时可一键跳回三维结构验证，并预置好观察状态
- [ ] 创新点四：**费曼式反向讲解**——答对后要求复述，把识别性掌握推进到生成性掌握
- [ ] 创新点五：**数据源隔离防幻觉**——数值题由程序计算，结构参数只能经工具从 COD 数据集读取
- [ ] 说明创新相对通用方案的具体增益（每条创新都应有“通用问答模型做不到什么”的对比）

### 2.4 实施显著性（25 分）

- [ ] 真实上线：H5 已部署，提供可访问网址 ✓
- [ ] 真实用户：山东大学结构化学课程（联系张冬菊教授课题组落实）
- [ ] 可量化实践数据：活跃用户数、答题数、首次正确率、**答错后变式题正确率**、掌握度提升、测验成绩对比、满意度问卷
- [ ] 数据可核查：保留后台截图、问卷原件、测验原始成绩（支撑材料附上）
- [ ] 对照实验：实验班/对照班或前后对照设计（见方案 §8.2）

### 2.5 推广适配性（10 分）

- [ ] 零部署门槛：纯前端 + Serverless，无需服务器运维
- [ ] **零 token 成本接入**：BYOK 模式下使用者自带模型 Key，学校无需承担 AI 调用成本
- [ ] 数据可扩展：新增晶体只需按格式添加数据文件并注册索引
- [ ] 能力可迁移：能力图谱方法论可复制到其他化学课程（如有机化学分子构型、配位化学）
- [ ] 微信小程序 skill 代码已就绪：待正式版开放 AI 能力即可平移启用
- [ ] 配套实施路径：提供《使用手册》与《教学应用指南》作为支撑材料

### 4.2 第二段：核心场景实操（2:00 - 8:00）

**场景 A：演示模式（2:00 - 3:30）**

| 时间 | 内容 |
|---|---|
| 2:00-2:15 | 输入：“给学生讲一下 NaCl 里为什么是 6 配位” |
| 2:15-3:10 | 智能体自动编排演示序列：球棍模型 → 高亮 Na⁺ 与周围 6 个 Cl⁻ → 打开八面体空隙 → 切 CPK 模型 → 开对称元素。全程只点“下一步” |
| 3:10-3:30 | 强调：**操作与讲解不再互相打断**；演示脚本可保存复现 |

**场景 B：问答练习板块（3:30 - 6:30）—— 全场核心，时间最长**

| 时间 | 内容 |
|---|---|
| 3:30-4:00 | 选择知识点“最密堆积的空隙分布”，智能体**边讲边操控视图**：切到 Cu 型 → 打开八面体空隙图层 → 分步解说 |
| 4:00-4:20 | 讲解卡底部点“我懂了，出题吧”，智能体出题：“Mg 型晶体中每个球周围有几个正八面体空隙？”4 个大按钮选项 |
| 4:20-4:35 | 作答“8 个” → 展示反馈卡：正误标记 + 解析 + 错项分析 |
| 4:35-5:15 | **答错深入讲解**：智能体自动打开空隙图层、高亮中心球周围空隙、旋转视角，引导自己数出“6 个”；指出错误认知根源：“你可能是把八面体的 8 个面当成了空隙数”。**这是本作品最区别于通用问答模型的一幕** |
| 5:15-5:40 | 出同知识点**变式题**：“那么 Cu 型（A1）中每个球周围有几个正八面体空隙？”→ 作答正确 |
| 5:40-6:10 | **晶体结构直达链接**：点反馈卡上的「去看结构」，一键跳转到对应三维视图，**并已预置好观察状态**（空隙图层已开、角度已调好）。强调：做题时能立刻回到结构里自己验证 |
| 6:10-6:30 | 小结：讲解 → 练习 → 反馈 → 溯源 → 复述，完整学习闭环 |

**场景 C：主动服务（6:30 - 7:15）**

| 时间 | 内容 |
|---|---|
| 6:30-6:50 | 使用者提问：“金刚石为什么是 4 配位”，智能体自动开键图层、高亮四面体 |
| 6:50-7:15 | 停留在 Mg 型晶体 50 秒未操作，智能体**主动浮出提示**：“要我把四面体空隙和八面体空隙打开对比一下吗？” 强调：**不等提问，主动服务** |

**场景 D：费曼式反向讲解（7:15 - 8:00）**

| 时间 | 内容 |
|---|---|
| 7:15-7:35 | 答对后智能体邀请：“试着用你自己的话说说，为什么 Mg 型是六方最密堆积，而 Cu 型是立方最密堆积？” |
| 7:35-7:55 | 使用者复述，智能体指出表述中的概念漏洞并给出对应观察动作 |
| 7:55-8:00 | 强调：把**识别性掌握**推进到**生成性掌握** |
