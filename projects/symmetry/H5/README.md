# 对称视界 · Symmetry Viewer

面向**高校教学**的 Web 应用：识别**分子 / 晶体**的对称元素、点群、空间群，并以 3D 方式精细展示对称元素（纯前端，无后端）。

## 功能特性

- **分子点群识别**：覆盖 46 个点群（32 晶体学点群 + C5/D5 五重轴族 + I/Ih + 连续群 C∞v / D∞h / Kh），自动检测旋转轴 Cn、旋反轴 Sn、反映面 σ、反演中心 i
- **确定性对称检测**：采用**原子几何候选 + 对称性验证**——由单原子方向 / 原子对中点 / 三点旋转轴构造候选方向，对**无主轴高阶群**再补充**解析方向候选**（正二十面体黄金比方向、立方体基本方向，使 C₆₀/SF₆/CH₄ 精确命中），逐一用"操作是否为对称"验证；同一条轴以真旋转 Cₙ 与旋反 Sₙ **同轴拆列**并存。替代角度网格采样，**完整、无漏检**（二茂铁 D5d 的 5 条 ⊥C₂ 与 σd、苯 D₆ₕ、C₆₀ Iₕ 的 6C₅+10C₃+15C₂+15σ 均补全）。方法参考 SYVA 对称分析程序（L. Gyevi-Nagy & G. Tasi，*SYVA: a program to analyze symmetry of molecules based on vector algebra*，*Computer Physics Communications*, 2017，[文献](https://www.sciencedirect.com/science/article/pii/S0010465517300310)）
- **专业对称元素命名**：按特征标表/Schoenflies 惯例——σh / σv / σd、C₂′ / C₂″（按"是否过配体/间隙"几何判定）、主轴 = 最高真旋转 Cn + 旋反 Sn 并存、C₂ᵥ 用 σv(xz)/σv(yz) 坐标、D₂/D₂ₕ 用 C₂(x/y/z)/σ(xy…)、高阶群（Oh/Td/Ih）坐标法向 σh / 对角 σd 等；同共轭类多个元素加 `(n)` 序号
- **对称元素 3D 展示**：Cn 轴（多边形棱柱 + 末端 n 边形符号）、Sn 轴（空心符号）、σ 面（**矩形**半透明面 + 边框，标签置于矩形角内侧）、反演中心 i，颜色按类型（σv/σd/σh 不同色）；轴记号参与深度遮挡（前端可见、后端被分子遮挡）
- **默认显隐**：有主轴群默认只显示主轴；Cs 显示反映面、Ci 显示反演中心；下拉列表可勾选隐藏/重新显示
- **初始视角对齐**：使主轴垂直屏幕（正对观察者）/ 对称面平行屏幕；双击复位也回到该朝向
- **对称操作教学动画**：对已显示的对称元素点击播放——分子实时对称运动 + 半透明副本定格对比，**对称元素与辅助几何全程不动（操作基准）**；Sn 旋反映动画额外以**镜面**展示其中的反映面（进入反映阶段变亮）；控制：播放/暂停、逆变换（逆向复合）、再次操作（正向复合）、重置变换、进度拖拽（拖动即暂停），旋转按阶次转一个对称操作角（360/n），角速度/时长可调
- **等价原子 & 稳定化子**：单击原子高亮，显示其**等价原子**（轨道）与**稳定化子**（保持该原子的对称操作**子群**，标注群阶、群元名带信息面板序号），其余原子/键/对称元素/标签虚化
- **原子名称标签**：可在原子球心显示元素符号（大小∝半径、暗/亮原子黑白字）
- **中英双语界面**：设置面板可切换（中/英），化学术语、分子命名按 IUPAC/群论标准翻译；群符号按主字母**斜体**/下标**正体**排版
- **晶体空间群识别**：230 个空间群（基于 [moyo](https://github.com/spglib/moyo) 的 WASM 绑定 `@spglib/moyo-wasm`）
- **内置示例库**：27 个分子 + 2 个晶体示例，覆盖多样点群；分子组按点群族序 `C→D→T→O→I→S→Cs→Ci` 排列，示例名/化学式随语言切换
- **外观自定义**：背景色、对称元素颜色（按当前结构实际元素动态显示）、原子缩放、键粗细、标签字号、动画参数

## 运行

```bash
cd H5
npm install
npm run dev      # 开发模式（http://localhost:5173）
npm run build    # 生产构建（输出 dist/）
```

## 使用

| 操作 | 说明 |
|---|---|
| 左键拖动 / 右键拖动 / 滚轮 | 旋转 / 平移 / 缩放 |
| 双击 | 复位视角（回到主轴正对屏幕朝向） |
| **单击原子** | 高亮该原子，显示**等价原子**与**稳定化子（群阶）**，其余虚化 |
| 顶部下拉 | 切换内置示例（分子按点群族序；晶体组后置） |
| 对称元素 ▶ | 播放该元素的对称操作教学动画（进度条可拖拽/暂停；⏮ 逆变换、⏭ 再次操作、⟲ 重置） |
| 辅助几何 | 显示参考几何（甲烷立方体含四面体/对角线、过氧化氢二面角矩形） |
| 原子标签 | 在原子球心显示元素符号 |
| ⚙ 设置 | 背景色、对称元素颜色、原子/键/标签、语言、动画参数、恢复默认 |

## 验证结果（识别）

| 结构 | 识别结果 |
|---|---|
| 甲烷 CH₄ | Td（S₄ + 4C₃ + 6σd） |
| 苯 C₆H₆ | D6h（C₆ + 3C₂′ + 3C₂″ + 3σᵥ + 3σd + σh + S₆ + i） |
| 氨 NH₃ / 水 H₂O | C3v / C2v |
| 六氟化硫 SF₆ | Oh（3C₄ + 6C₂ + 3σh + 6σd + i） |
| 富勒烯 C₆₀ | Ih（6C₅ + 15σ + i） |
| **二茂铁** | D5d（C₅ + 5C₂ + 5σd + S₁₀ + i） |
| 碗烯 C₅ₕ / 三苯甲烷 C₃ / 乙烷 D3d | C5v / C3 / D3d（C₃ + 3C₂ + 3σd + S₆ + i） |
| NaCl / CsCl | Fm-3m（225）/ Pm-3m（221） |

## 目录结构

```
H5/
├── index.html                    # 单页入口 + UI
└── src/
    ├── main.js                   # 入口：加载结构 + 识别 + 渲染 + UI/动画/原子选中事件
    ├── i18n/index.js             # 中英双语字典、t()、群符号/不可约表示格式化
    ├── data/
    │   ├── elements.js           # 元素 CPK 配色/半径表
    │   ├── settings.js           # 设置存储（localStorage 持久化）
    │   ├── examples-index.js     # 内置示例库（含中英文名、辅助几何声明）
    │   └── STRUCTURE_SOURCES.md  # 示例数据来源记录（CCCBDB/COD）
    ├── core/
    │   ├── structure.js          # 统一结构模型（分子/晶体）
    │   ├── lattice.js            # 分数↔笛卡尔、晶胞几何
    │   └── parsers/              # XYZ/GJF/XSD/CIF/POSCAR 解析器
    ├── symmetry/
    │   ├── detectElements.js     # 确定性对称检测：原子几何候选 + 验证（参考 SYVA）
    │   ├── operations.js         # 对称操作矩阵 + 检测 + 空间群操作→对称元素
    │   ├── pointGroup.js         # 分子点群识别（惯性矩 + 判定表 + 候选/轨道补全）
    │   ├── elementNaming.js      # 专业命名（σh/σv/σd、C₂′/C₂″、坐标、等价类序号）
    │   ├── groupOperations.js    # 群操作生成、等价原子/稳定化子（群阶、专业群元名）
    │   ├── groupTable.js         # 点群名称/晶系映射
    │   ├── characterTables.js    # 特征标表（基函数分线性&旋转 / 二次函数两列）
    │   └── spaceGroup.js         # 晶体空间群识别（moyo-wasm 封装）
    ├── render/
    │   ├── materials.js          # 原子材质 + 光照
    │   ├── scene-builder.js      # 分子/晶体场景 + 辅助几何（立方体含四面体/二面角）
    │   ├── symmetry-draw.js      # 对称元素 3D 渲染（矩形反映面、轴记号深度遮挡）
    │   ├── animation.js          # 对称操作教学动画（播放/暂停/逆/再次/重置/进度拖拽）
    │   └── viewer.js             # 渲染循环、四元数轨道相机、交互、原子拾取、视角对齐
    └── ui/
        └── info.js               # 信息面板（对称元素分组命名 + 等价原子/稳定化子 + 特征标表）
```

- [three.js](https://threejs.org/)（3D 渲染）
- [@spglib/moyo-wasm](https://www.npmjs.com/package/@spglib/moyo-wasm)（晶体空间群识别）
