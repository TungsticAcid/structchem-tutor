# chem-agent

结构化学教学智能体 —— **一个中枢 + N 个可插拔教学工具**。

把原子轨道、分子对称性与晶体结构三个教学工具汇聚到同一个智能体之下，
面向结构化学课程的教学演示、练习与自主探究。

---

## 功能

### 三个教学模块

- **轨道视界**：氢原子/类氢离子轨道、量子数、节点、波函数实数解与复数解、电子云与概率密度；
- **点群观鉴**：分子对称性、对称元素与操作、点群判定、特征标表；
- **晶典在线**：晶体结构、晶胞、点阵与结构基元、图层/截面/配位数、晶体对比。

### 智能体

- 讲解、出题、判卷、演示编排与主动建议；
- 工具权限按教学阶段统一控制：出题阶段不提供会改变画面的工具，判卷阶段以诊断为主；
- 知识条目只在需要时加载正文，避免把整套资料塞进对话。

### 统一前端

首页门户、模块页、对比页与晶体库页共用一个入口；支持深色/浅色主题、
中文/English 切换，以及桌面与移动端布局。

## 快速开始

安装依赖并运行全部自检（在仓库根目录）：

```bash
npm install
npm test
```

以下构建命令在仓库根目录执行：

```bash
node tools/build-web.mjs      # 输出 apps/web/dist
```

启动开发服务器（保持运行）：

```bash
cd apps/web
npm run dev        # → http://localhost:3001
```

打开首页后，点「开始探索」进入三个教学模块，或点「问智能体」直接打开侧边栏。
首次使用智能体时，在面板右上角「设置 → 模型服务」填写自己的 API Key；
密钥只保存在本机浏览器。

另开一个终端，在仓库根目录进行真实浏览器验证（截图、抓控制台报错、执行表达式）：

```bash
node tools/screenshot.mjs --console
node tools/screenshot.mjs --wait-for "window.__chemAgent" --out tmp/shot.png
```

逐项功能验收（同样需要开发服务器在运行；**会调用真实 LLM、消耗额度，故不进 `npm test`**）：

```bash
npm run verify:live -- --key-file "<仓库外的密钥文件>" --dry   # 零额度：只验接线
npm run verify:live -- --key-file "<仓库外的密钥文件>"          # 真跑三层断言
```

> 密钥只从仓库外的文件读取，不写入仓库、不打印到输出。

## 设计要点

- **模块可插拔**：模块通过 `packages/module-contract` 的契约向中枢声明能力；
  缺少能力时如实降级，而不是假装可用。
- **权限按教学阶段控制**：讲解阶段可边讲边演示；出题阶段不提供会改变画面的工具；
  判卷阶段以诊断为主。
- **数值由程序计算**：密度、体积、最近邻、点群、能级等结果来自代码，不依赖模型口算。
- **渐进式知识加载**：知识条目先给清单，正文按需读取。

## 知识库与命名

知识条目按模块存放在 `packages/knowledge/<module>/`。每个知识库的骨架与写作要求
见该目录下的 `README.md`。

条目 id 统一带命名空间：

```text
crystal:C4-2     晶体模块
orbit:K3-1       轨道模块
symmetry:P2-3    对称模块
shared:S1-2      共享知识库
```

通用教学技能不带命名空间，放在 `packages/skills/common/`，供各模块共用。

## 版权约定

知识条目不摘录教材原文：

- ✅ 吸收事实与逻辑，用自己的语言组织
- ✅ `source` 字段标注教材与章节（属引用）
- ❌ 不复制原文表述、不收录教材习题原文、不上传扫描页
