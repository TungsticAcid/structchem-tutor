## 各知识点应覆盖的内容

### C1 点阵型式（5 条）

- 14 种布拉维点阵与七个晶系的关系
- 点阵记号的读法（`cF` = 立方 + 面心；`hP` = 六方 + 简单）
- **★ CsCl 型为什么是简单立方而非体心立方**（经典易错点）
- 点阵型式 ≠ 晶系（两个概念的区分）
- 如何从三维视图判断点阵型式（配合"打开点阵点图层"）

### C2 结构基元（4 条）

- 结构基元的定义：一个点阵点所代表的结构内容
- 结构基元数 = 晶胞原子数 ÷ 点阵点数
- **★ "原子环境相同"≠"被点阵平移联系"**（金刚石的 8 个 C 全等效，结构基元却是 C₂）
- 结构基元与实际晶胞内容的关系

### C3 堆积方式（7 条）

- A1（立方最密）/ A2（体心）/ A3（六方最密）/ A4（金刚石型）
- 空间利用率：74.05% / 68.02% / 74.05% / 34.01%
- ABCABC 与 ABAB 层序的区别
- A2 为什么不是最密堆积
- 密堆积方向与晶胞对角线的关系

### C4 配位环境（6 条）

- 配位数与配位构型的区别
- NaCl 型 6:6、CsCl 型 8:8、ZnS 型 4:4
- **离子半径比与配位数的关系**（半径比规则）
- 分子晶体为什么没有经典配位数
- 配位多面体的识别

### C5 空隙分布（6 条）

- 正四面体空隙与正八面体空隙的几何
- **★ 晶胞内空隙总数 ≠ 每个球周围的空隙数**（前者 fcc 是 4，后者是 6）
- A1/A3 中空隙数与球数的比例
- 空隙占有率与填隙率
- 空隙位置如何从三维视图数出来

### C6 空间群与对称元素（6 条）

- 对称元素类型：旋转轴、镜面、反演中心、旋转反演轴
- 空间群符号的读法（`Fm-3m` 的每一部分什么意思）
- 点群与空间群的区别
- 等效点系（Wyckoff 位置）与原点选择
- 对称元素在三维视图中怎么找

### C7 晶胞参数（5 条）

- 七个晶系的晶胞参数特征
- 晶胞体积的通用公式
- 由晶胞参数算密度：ρ = Z·M/(N_A·V)
- 最近邻距离的计算
- 晶格常数与原子半径的关系

### C8 结构—性能关联（5 条）

- 金刚石与石墨：同为碳，性质为何迥异
- 石墨的层状结构与润滑性、导电各向异性
- 同素异形体与同质多象
- 离子晶体的稳定性与晶格能
- 结构与物理性质的一般关联思路

## 蒸馏时特别注意的两处

这两处是本项目在数据核查中**真实发现过错误**的地方，教材表述也常有不一致，
编写条目时须格外小心并标注清楚：

| 易错点 | 正确表述 |
|---|---|
| CsCl 的点阵型式 | **简单立方 cP**（不是体心立方——Cs⁺/Cl⁻ 不同种，不构成体心点阵） |
| 黄铁矿 FeS₂ 的点阵型式 | 空间群 `Pa-3` 是 **P 点阵**，即简单立方；Fe²⁺ 的类面心排列由空间群对称操作产生，**不是点阵平移** |

> 详见 `D:\xjl\program\crystal\activity\数据核查报告.md`（仓库外）。
