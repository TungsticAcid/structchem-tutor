## ★ 与其它模块的边界（写之前先想清楚，否则会各写一份）

| 主题 | 归谁 | 理由 |
|---|---|---|
| 对称操作、点群、特征标、选律、手性 | **本模块（P1–P4）** | 只有 symmetry 一个消费者 |
| 晶体对称性**的对称性一侧**（操作、空间群与点群的关系、五次轴禁令） | **本模块（P5）** | 讲的是"对称性"，不是"晶体结构" |

| 特征标表**数据**、点群名称表 | `symmetry/characterTables.js`、`groupTable.js` | 是**数据**不是条目；晶体与轨道模块将来也会 import |

**准入判据**（何时该迁去 `shared/`）：这条知识会不会被**两个以上模块**引用？
会 → 总库；只在某一模块用得上 → 留在该模块。
群论基础（共轭类、不可约表示、选择定则）现在只有 symmetry 一个消费者，
故先归它——**将来 orbit 讲轨道对称性要用时再迁**，而不是"可能有用"地预先塞进总库。

### 工作流（与结构化学那两本相同）

⚠️ **三本关键书是扫描件、无文字层**——必须用 `pymupdf` 把目标页**渲染成图片**再读图，
不能直接 `get_text()`（实测前 6 页均 0 字符）。两本有文字层的（李新征讲义、Visual Group Theory）
可以直接提取，先生成它们能省下大量读图时间。

```python
import pymupdf
d = pymupdf.open('…pdf')
pix = d[页码].get_pixmap(dpi=200)     # dpi 200 足够读正文与公式
pix.save('tmp/page.png')
```

### ★ 术语纪律（跨书最容易出的错）

三套书对同一个概念用的名字**不一样**，而本模块要同时被化学与数学背景的使用者读：

| 概念 | 化学书（Cotton） | 数学书 | 物理书（马中骐） | **本模块采用** |
|---|---|---|---|---|
| 群元素的分类 | 类 | 共轭类 | 共轭类 | **共轭类**（数学/物理一致，且更准确） |
| 表示的分解 | 约化 | 不可约分解 | 约化 | **约化 / 不可约分解**（视语境） |
| 对称操作的乘法 | 乘积 | 群乘法 | 群乘法 | **群乘法** |
| 特征标表的一行 | 不可约表示 | 不可约特征标 | 不可约表示 | **不可约表示**（跟随化学惯例，是教学主线） |

**判据**：以化学惯例为**教学主线**（学生要算的是红外活性、手性），
但定义与定理的表述以数学书的严格形式为准——两者冲突时，
条目里**两个名字都写出来**并说明取舍（如"共轭类（化学书里也叫『类』）"）。

参考：`packages/i18n/glossary.js`（术语真源）应把这张表纳入。
