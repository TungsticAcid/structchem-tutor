# 总知识库 shared

存放**跨模块共用**的学科事实。判据：这条知识是否会被两个以上模块引用？

只装真正共用的内容，避免变成什么都往里塞的杂物间。

## 应装什么

| 类别 | 会被谁引用 |
|---|---|
| 对称性与群论基础 | crystal、symmetry |
| 量子力学基础 | orbit、crystal（成键部分） |
| 化学键理论 | crystal、orbit |
| 结构—性能关联总纲 | crystal、orbit |
| **跨模块概念映射** | 全部 |

## 编号

用 `shared:` 前缀，如 `shared:S1-2`。

## ★ 优先建设顺序

三个模块的交集集中在**对称性**上，所以优先建对称性部分。
