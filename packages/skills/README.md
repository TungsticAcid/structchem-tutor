## 二、技能格式

```js
{
  name: 'feynman',
  title: '费曼式反向讲解',
  desc: '让学生用自己的话复述，把"识别性掌握"推进到"生成性掌握"',
  when: '学生答对之后；或学生表示"好像懂了"但说不清时',   // ★ 触发条件
  steps: [ '邀请复述……', '完整听完不打断……', /* … */ ],
  phrases: [ '试着用你自己的话说一遍……' ],              // 话术模板
  exit: '学生能完整、无概念错误地讲清该知识点',            // ★ 退出条件
  cautions: [ '不要在学生复述中途打断纠正' ],             // ★ 注意事项（含"不要做什么"）
}
```

### `when` / `exit` / `cautions` 三个字段缺一不可

它们构成方法的完整约束：

| 字段 | 回答的问题 | 缺失的后果 |
|---|---|---|
| `when` | 什么时候该用这个技能？ | 模型不知道该何时进入 |
| `exit` | 什么时候算用完？ | 会无限循环或过早退出 |
| `cautions` | 途中有何禁忌？ | 会做出损害教学效果的动作 |

只写 `steps` 是不够的。

## 三、通用技能清单（`common/`）

以下 6 个**不依赖学科**，可从 orbit 项目整体平移
（现成实现在 `projects/orbit/H5/skills/index.js`）：

| 名称 | 用途 | 关键约束 |
|---|---|---|
| `feynman` | 费曼式反向讲解 | 复述中途不打断 |
| `socratic` | 苏格拉底式追问 | **追问不超过 3 轮**；学生挫败时切换讲解 |
| `misconception-probe` | 错因探查 | 不用"你错了"开头 |
| `worked-example` | 范例精讲 | 范例不超过 3 步 |
| `spaced-repetition` | 间隔复习 | 每次最多复习 2 个知识点 |
| `analogy` | 类比教学 | **必须附"类比失效边界"说明** |

> `analogy` 的边界要求尤其重要：类比不附失效边界，会植入新的误解——
> 这是类比教学最大的坑。

**状态**：⏳ 待从 orbit 平移

## 五、加载机制

与知识库同理：**完整步骤不进系统提示**，只放清单（名称 + 一句话说明），
模型需要时调用 `loadSkill(name)` 才拉取。

**硬约定**：**未调用 `loadSkill` 取得完整步骤时，不得凭印象执行某个教学法。**
这条写在 `packages/agent-core/nodes/constraints.js` 的 `teach` 节点禁令里。
